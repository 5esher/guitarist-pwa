# CODEX_RULES.md — правила работы Codex

## 1) Источник истины

- Главный документ требований: MASTER_PROMPT_PWA_Guitarist.md
- Любые изменения требований пользователь делает:
  1) правкой MASTER_PROMPT_PWA_Guitarist.md или отдельного SPEC.md (если появится)
  2) коммит + push
- Codex обязан каждый раз начинать с чтения MASTER_PROMPT_PWA_Guitarist.md

## 2) Стратегия работы

Всегда цикл:

1) прочитать требования
2) составить план
3) внести изменения
4) запустить проверки
5) исправлять, пока всё не зелёное
6) commit + push

## 3) Ветка

Работать только в ветке: codex/dev

## 4) Формат выдачи

Для каждого этапа из мастер-промпта:

- список файлов (создать/изменить)
- полный код каждого файла (не diff)
- команды запуска/проверки
- строка: СТАТУС: ГОТОВО
